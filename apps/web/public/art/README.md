## Implementation notes
- Use hero artwork with `object-fit: cover`.
- Add text-safe dark overlays in CSS rather than baking text into images.
- Use textures at low opacity, generally 3–12%.
- Use celestial crops as decorative artwork, not factual chart output.
- Keep actual astrology charts generated from real application data.
- These are starter assets extracted from generated boards and may need final production regeneration at larger native dimensions before launch.
